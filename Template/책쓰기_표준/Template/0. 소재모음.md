# 소재모음

> 기획안과 목차로 정제되기 전, 떠오른 사건·기억·대화·질문·자료를 보관하는 곳이다. 한 소재가 아직 책의 논지에 맞는지 판단하지 못했어도 버리지 않고 기록한다.

## 사용 방법

- 소재 하나당 `### M-번호. 제목`을 하나씩 만든다. 번호는 추가 순서대로 붙이며, 삭제하지 않는다.
- 상태 아래 줄에는 기억이 생생할 때의 말과 장면을 최대한 날것 그대로 적는다 — 해석하거나 다듬지 않는다.
- 메모는 선택이다. 사실 확인, 기억의 불확실성, 사생활·실명, 짧은 해석이나 활용처 등 덧붙일 말이 있을 때만 쓰고, 없으면 생략한다.
- 기획안이나 목차에 채택된 뒤에도 원문은 여기 그대로 둔다. 상태만 갱신한다.

## 빠른 등록 양식

### M-번호. 소재 제목

- 상태: 수집 / 검토 / 채택 / 보류 / 제외
- (있었던 일, 생각, 대사를 최대한 날것 그대로 적는다)
- 메모: (선택) 사실 확인·사생활 주의, 짧은 해석, 활용 후보 등 — 덧붙일 게 있을 때만
